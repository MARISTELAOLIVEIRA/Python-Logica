Exemplo resolvido Estruturas de decisão tkinter

Calculadora de IMC com janela

Duas soluções: primeiro com if, depois com match. A janela é a mesma; só muda o jeito de decidir.

J1 · a janela

Pense numa balança de farmácia

Por fora, você vê o visor e o botão. Por dentro, um mecanismo faz a conta. No programa é igual: a janela é o visor, e a função classificar é o mecanismo.

  1. ⌨️VisorEntry: você digita o peso e a altura.
  2. 👆BotãoButton: o clique chama calcular().
  3. ⚙️Mecanismoclassificar(imc): o if ou o match escolhe a faixa.
  4. 📟Visor de novoLabel: a resposta aparece.

Como rodar no seu computador

  1. Copie o código

    1

    Escolha a aba lá embaixo e salve como imc_tk_if.py (ou imc_tk_match.py).

  2. Rode no terminal

    2

    No Windows: python imc_tk_if.py. No Mac ou Linux: python3 imc_tk_if.py.

  3. Teste

    3

    Digite peso e altura e clique em Calcular. A vírgula funciona: 1,75.

O tkinter já vem com o Python. Não precisa instalar nada.

if / elif / else

Testa as condições de cima para baixo e para na primeira verdadeira. Por isso elif imc < 25 não precisa de imc >= 18.5.

match / case

Compara padrões. Para faixas de valores, quem decide é o if depois do case (a guarda). O case _ é o "senão".

O match só existe a partir do Python 3.10. Num Python mais antigo, dá erro de sintaxe.

V1 · validação da entrada

Nunca confie no que foi digitado

Quem usa o programa pode errar ou testar de propósito. Validar a entrada é a primeira linha de defesa em segurança.

  1. Validação 1: é número?

    try

    O float() dá ValueError com texto. O except pega o erro e mostra um aviso em vez de quebrar.

  2. Validação 2: faz sentido?

    if

    Número não basta: peso negativo ou altura 0 não existem. E o return para a função ali mesmo.

P1 · para pensar

E se alguém digitar nan?

Teste no peso. O Python aceita float("nan") ("não é um número", em inglês) e a janela mostra Seu IMC é nan. A validação deixou passar!

  • Desafio 1: descubra por que o nan passou pelo if peso <= 0. Dica: teste print(float("nan") <= 0).
  • Desafio 2: barre o nan e o inf. Dica: import math e math.isfinite(peso).
  • Desafio 3: qual peso máximo faz sentido? Crie a validação com uma mensagem no tom da sua calculadora.

Esse é o pensamento de quem trabalha com segurança: procurar a entrada que ninguém imaginou.
