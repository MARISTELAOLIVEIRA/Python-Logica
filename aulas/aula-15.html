P1 · o problema

O código que se repete

Seu programa valida a senha no cadastro, de novo na troca de senha e de novo no login. Mudou uma regra? Precisa mudar em três lugares, e vai esquecer um. A saída é escrever uma vez e chamar quantas vezes quiser.

C1–C3 · conceitos

Escreva uma vez, use sempre

C1

def, parâmetros e return

def cria a função. Os parâmetros são as entradas, entre parênteses. O return devolve o resultado para quem chamou.

Quem chama passa os argumentos: os valores de verdade.

1def classificar_senha(senha):2    if len(senha) < 8:3        return "Fraca"4    if senha.isalpha() or senha.isdigit():5        return "Média"6    return "Forte"78print(classificar_senha("abc"))         # Fraca9print(classificar_senha("abcdefgh"))    # Média10print(classificar_senha("Senac2026!"))  # Forte
C2

Escopo: local e global

Variável criada dentro da função só existe lá dentro (local). A de fora (global) pode ser lida por todos, mas mexer nela de dentro da função é pedir confusão.

Regra prática: o que a função precisa entra por parâmetro e o que ela produz sai pelo return.

1LIMITE = 3   # global23def bloqueado(tentativas):4    excesso = tentativas - LIMITE   # local5    return excesso >= 067print(bloqueado(2))   # False8print(bloqueado(3))   # True9# print(excesso)  # erro: só existe na função
C3

Um menu que chama funções

Com as ferramentas viradas funções, o programa principal fica curto: um menu que chama cada uma.

1def cifrar(texto, chave):2    resultado = ""3    for letra in texto.upper():4        if letra.isalpha():5            pos = (ord(letra) - 65 + chave) % 266            letra = chr(pos + 65)7        resultado += letra8    return resultado910print(cifrar("Senha", 3))     # VHQKD11print(cifrar("VHQKD", -3))    # SENHA
CU1 · caso de uso

O menu da ferramenta de segurança

Ator: Funcionário da TI

Objetivo: Usar várias ferramentas num programa só.

Fluxo principal

  1. O programa mostra o menu: 1 validar senha, 2 cifrar mensagem, 3 relatório, 0 sair.
  2. O usuário escolhe uma opção.
  3. O programa chama a função certa.
  4. Volta ao menu até o usuário escolher sair.

E se...

  • O usuário digita uma opção que não existe: o menu avisa e mostra de novo.

Para pensar

  1. Quais funções esse menu chama? Que parâmetros e que retorno cada uma tem?
  2. O que fica no programa principal e o que fica dentro das funções?

Matemática

f(x) = 2x é uma função da matemática. def f(x): return 2 * x é a mesma coisa em Python.

Artes
