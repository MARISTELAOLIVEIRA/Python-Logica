C1

Módulos: math, random e secrets

Módulo é código pronto que você importa com import. O math tem contas, o random sorteia.

Para senhas e tokens, use o secrets: ele é feito para segurança. O random é previsível demais para isso.

C2

try, except e finally

O try tenta executar. Se der erro, o except trata, em vez de o programa quebrar na cara do usuário. O finally roda de qualquer jeito.

Trate o erro que você espera (como ValueError), não todos de uma vez.

1entrada = "dezoito"2try:3    idade = int(entrada)4    print(f"Idade: {idade}")5except ValueError:6    print("Isso não é um número.")7finally:8    print("Verificação concluída.")910# Isso não é um número.11# Verificação concluída.
C3

PEP 8, docstrings e depuração

A PEP 8 é o guia de estilo do Python: nomes em snake_case, 4 espaços, linhas não muito longas. Código no padrão é código que outra pessoa entende.

A docstring explica o que a função faz. O depurador do VS Code para o programa numa linha e mostra o valor de cada variável.

1def contar_suspeitos(registros, limite=3):2    """Devolve quem errou limite vezes ou mais."""3    suspeitos = []4    for u in registros:5        if u in suspeitos:6            continue7        if registros.count(u) >= limite:8            suspeitos.append(u)9    return suspeitos1011lista = ["ana", "ana", "ana", "bia"]12print(contar_suspeitos(lista))   # ['ana']

CU1 · caso de uso

Gerar uma senha temporária

Ator: Equipe de TI

Objetivo: Criar uma senha segura para um funcionário novo.

Fluxo principal

  1. A TI informa o tamanho da senha.
  2. O sistema gera a senha com o módulo secrets.
  3. Confere se ela tem todos os tipos de caractere.
  4. Mostra a senha uma única vez.

E se...

  • A TI digita "doze" em vez de 12: o try e except tratam o erro e pedem de novo.
  • O tamanho é menor que 8: o sistema recusa.

Para pensar

  1. Por que secrets, e não random?
  2. Que exceção o int() levanta com um texto?
