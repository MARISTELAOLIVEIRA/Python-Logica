C1–C3 · conceitos

Dados com nome e sobrenome

C1

Tuplas: a lista que não muda

A tupla é como uma lista, mas entre parênteses e imutável: depois de criada, não muda.

Use para dados que não devem ser alterados por engano, como as coordenadas de um servidor ou os perfis possíveis do sistema.

1PERFIS = ("admin", "funcionario", "visitante")2print(PERFIS[0])        # admin3print(len(PERFIS))      # 34# PERFIS[0] = "root"    # erro: tupla não muda
C2

Dicionários: chave e valor

O dicionário guarda pares chave: valor, entre chaves. Você acessa pelo nome, não pela posição.

Incluir e alterar é a mesma coisa: d[chave] = valor. Remover: del d[chave].

1usuario = {2    "login": "bia",3    "perfil": "funcionario",4    "ativo": True,5}6print(usuario["perfil"])   # funcionario78usuario["perfil"] = "admin"         # altera9usuario["email"] = "bia@senac.br"   # inclui10del usuario["ativo"]                # remove11print(usuario["perfil"])   # admin
C3

Percorrendo e consultando

keys() devolve as chaves, values() os valores e items() os pares.

get() consulta sem dar erro quando a chave não existe: devolve None ou o valor padrão que você escolher.

1permissoes = {2    "bia": ["ler", "escrever"],3    "caio": ["ler"],4    "root": ["ler", "escrever", "apagar"],5}67for login, lista in permissoes.items():8    print(f"{login}: {', '.join(lista)}")910print(permissoes.get("ana", "sem cadastro"))11# sem cadastro
CU1 · caso de uso

Consultar e mudar as permissões

Ator: Administrador do sistema

Objetivo: Ver e alterar o que cada usuário pode fazer.

Fluxo principal

  1. O administrador informa o login.
  2. O sistema mostra as permissões do usuário.
  3. O administrador acrescenta ou tira uma permissão.
  4. O sistema mostra a lista atualizada.

E se...

  • O login não existe: o get() devolve "sem cadastro" em vez de dar erro.
  • Alguém tenta mudar o próprio perfil para admin: o sistema não deixa.

Para pensar

  1. Qual é a chave e qual é o valor no dicionário de permissões?
  2. Por que os perfis possíveis cabem bem numa tupla?

S1 · conexão STEAM

Chaves de verdade

T

Tecnologia

Todo sistema de login tem uma tabela de usuários e permissões. O JSON que circula na internet é, na prática, um dicionário.

M

Matemática

Dicionário é uma função da matemática: cada chave (do domínio) aponta para um valor (da imagem).

E

Eletrônica

Um controle de acesso com cartões RFID guarda exatamente isso: o código de cada cartão como chave e a permissão como valor.
