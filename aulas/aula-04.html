C1–C4 · conceitos

Ferramentas e primeiras linhas

C1

Por que Python?

Python é legível, tem bibliotecas para quase tudo e é a linguagem queridinha da segurança da informação, da automação e da análise de dados.

Ele é interpretado: o interpretador lê e executa o seu script linha a linha. Também dá para testar no modo interativo, digitando direto no terminal.

C2

print() e comentários

O print() mostra algo na tela. Tudo depois do # é comentário: o Python ignora, e quem lê o código agradece.

1# meu primeiro programa2print("Olá, mundo!")3print("Turma de Python, presente!")
C3

Mensagens de erro não mordem

Erro é o Python dizendo onde ele se perdeu. Leia a última linha primeiro: ela diz o tipo do erro e a linha do problema.

Os mais comuns no começo: SyntaxError (escrita errada, como aspas faltando) e NameError (nome que não existe, como Print com P maiúsculo).

Cuidado: o Python diferencia maiúsculas de minúsculas. print funciona, Print não.

C4

GitHub: repositório, commit e push

O repositório é a pasta do projeto na nuvem. O commit é uma foto do código num momento. O push envia as fotos para o GitHub.

Sem instalar nada, o GitHub Codespaces abre um VS Code completo no navegador.
