P1 · o problema

Uma senha de 4 dígitos aguenta quanto tempo?

Um programa que testa 1.000 senhas por segundo leva quanto tempo para tentar todas as senhas numéricas de 4 dígitos? E de 6? E de 8? Hoje a gente faz essa conta em Python e descobre por que senha curta é senha fraca.

forca_bruta.py 
1por_segundo = 1000   # tentativas23for digitos in (4, 6, 8):4    combinacoes = 10 ** digitos5    horas = combinacoes / por_segundo / 36006    print(f"{digitos} dígitos: {horas:.1f} horas")78# 4 dígitos: 0.0 horas9# 6 dígitos: 0.3 horas10# 8 dígitos: 27.8 horas
C1–C3 · conceitos

Três famílias de operadores

C1

Aritméticos

+ - * / como na calculadora. // é a divisão inteira, % é o resto e ** é a potência.

Precedência: primeiro **, depois * / // %, por último + e -. Na dúvida, parênteses.

1print(7 / 2)     # 3.52print(7 // 2)    # 33print(7 % 2)     # 14print(2 ** 10)   # 10245print(2 + 3 * 4)     # 146print((2 + 3) * 4)   # 20
C2

Relacionais

Comparam dois valores e devolvem True ou False: == != > < >= <=.

Cuidado: = guarda um valor; == compara. Trocar um pelo outro é o erro mais clássico do semestre.

1tentativas = 32print(tentativas == 3)   # True3print(tentativas != 3)   # False4print(tentativas >= 5)   # False
C3

Lógicos

and só é verdadeiro se as duas partes forem. or é verdadeiro se pelo menos uma for. not inverte.

A tabela-verdade mostra todas as combinações possíveis.
