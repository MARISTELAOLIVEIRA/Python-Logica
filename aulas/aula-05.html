C1

Variáveis e tipos

Variável é um nome que guarda um valor na memória. Em Python, o sinal = é atribuição: guarda o valor da direita no nome da esquerda.

Os quatro tipos básicos: int (inteiro), float (com casas decimais), str (texto) e bool (True ou False). A função type() revela o tipo.

1usuario = "bia.silva"2idade = 193altura = 1.684admin = False56print(type(usuario))   # <class 'str'>7print(type(idade))     # <class 'int'>8print(type(altura))    # <class 'float'>9print(type(admin))     # <class 'bool'>
C2

input() sempre devolve texto

O input() pergunta algo ao usuário e devolve o que ele digitou. Sempre como texto, mesmo que seja um número.

Para fazer conta, converta: int(), float() e, no caminho de volta, str().

Cuidado: "19" + 1 dá erro. int("19") + 1 dá 20.

1idade = input("Sua idade: ")  # digite 192print(type(idade))   # <class 'str'>34idade = int(idade)5print(idade + 1)     # 20
C3

f-strings

Com um f antes das aspas, o que estiver entre chaves { } vira o valor da variável. É o jeito mais limpo de montar mensagens.

{valor:.2f} mostra o número com duas casas decimais.

1nome = "Bia"2dias = 19 * 3653print(f"{nome} já viveu cerca de {dias} dias.")4# Bia já viveu cerca de 6935 dias.56dolar = 5.47print(f"US$ 10 = R$ {10 * dolar:.2f}")8# US$ 10 = R$ 54.00
CU1 · caso de uso

Cadastrar um funcionário

Ator: Equipe de TI

Objetivo: Criar a ficha de um funcionário novo.

Fluxo principal

  1. A TI informa o nome e o usuário.
  2. Informa a idade.
  3. Informa se a pessoa é administradora (sim ou não).
  4. O sistema mostra a ficha formatada com f-string.

E se...

  • A idade é digitada como texto: o int() dá erro, e o programa precisa avisar em vez de quebrar.

Para pensar

  1. Qual é o tipo de cada dado (str, int, float, bool)?
  2. Por que o input() sozinho não serve para a idade?
