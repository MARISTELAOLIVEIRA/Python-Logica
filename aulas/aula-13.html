P1 · o problema

Centenas de registros, nenhuma variável sobrando

O servidor registrou cada tentativa de login da madrugada: o usuário e o IP. Criar uma variável para cada registro? Impossível. Hoje a gente guarda tudo numa lista e descobre quem tentou demais.

C1–C3 · conceitos

Uma variável, muitos valores

C1

Criando e acessando

A lista guarda vários valores em ordem, entre colchetes. Índices e fatiamento funcionam como nas strings.

A diferença: a lista pode ser alterada.

1ips = ["10.0.0.5", "10.0.0.7", "10.0.0.5"]2print(ips[0])       # 10.0.0.53print(ips[-1])      # 10.0.0.54print(len(ips))     # 35ips[1] = "10.0.0.9"6print(ips[1])       # 10.0.0.9
C2

Métodos de listas

Mexendo na lista: append() põe no fim, insert() põe numa posição, remove() tira pelo valor, pop() tira pela posição.

Analisando: sort() ordena e count() conta quantas vezes um valor aparece. O operador in diz se o valor está na lista.

MétodoFaz
append(x)põe x no fim
insert(i, x)põe x na posição i
remove(x)tira o primeiro x
pop()tira o último (e devolve)
sort()ordena
count(x)conta quantos x
x in listaTrue se x está na lista
C3

Achando os suspeitos

Para cada usuário diferente, conte quantas tentativas ele fez. Quem passou do limite vai para a lista de suspeitos.

1tentativas = ["ana", "caio", "ana", "root",2              "root", "ana", "root", "root"]3suspeitos = []45for usuario in tentativas:6    if usuario in suspeitos:7        continue   # já está na lista8    if tentativas.count(usuario) >= 3:9        suspeitos.append(usuario)1011suspeitos.sort()12print(f"{len(tentativas)} tentativas analisadas")13print("Suspeitos:", suspeitos)1415# 8 tentativas analisadas16# Suspeitos: ['ana', 'root']
CU1 · caso de uso

O relatório de acessos da madrugada

Ator: Equipe de segurança

Objetivo: Descobrir quem tentou entrar demais na madrugada.

Fluxo principal

  1. O sistema carrega a lista de tentativas de login.
  2. Conta as tentativas de cada usuário.
  3. Lista os suspeitos (3 tentativas ou mais).
  4. Mostra o relatório em ordem alfabética.

E se...

  • A lista está vazia: o relatório diz "nenhuma tentativa registrada".

Para pensar

  1. Que métodos de lista cada passo usa?
  2. Como evitar que o mesmo suspeito apareça duas vezes?
